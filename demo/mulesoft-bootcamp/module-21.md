# Module 21 — About the Author

This book was generated in conversation with an LLM — and that is the point. What you just read is also the demo content for the tool that renders it.

---

## 21.1 Who wrote this

**Yuri Syuganov** tests software for a living — a software engineer in test (SDET) with a long consulting practice. This bootcamp is a real artifact of that work: it was produced over a few days of structured ChatGPT conversations while onboarding into MuleSoft for an integration engagement, then saved chapter by chapter as markdown.

The workflow — long LLM conversations → markdown book → spatial tile viewer — turned out to be worth keeping, so the viewer became **Bookatlas**, the open-source engine you are reading this in.

```text
LLM conversation
   ↓
markdown chapters
   ↓
Bookatlas
   ↓
this page
```
